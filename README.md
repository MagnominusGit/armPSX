# armPSX

A PlayStation emulator for ARM and x86 handhelds and desktops.

The GPU, GTE and the controller and memory card protocols are ported from Mednafen's PS1 module
(GPL-2.0-or-later). The CPU, bus and scheduling are armPSX's own.
